# de-Ferra2020-kz Reproduction Scripts

This directory contains supporting scripts for the `./reproduce.sh` workflow.

---

## Quick Reference

| Script | Called by | Purpose |
|--------|-----------|---------|
| `reproduce_environment.sh` | `reproduce.sh --envt` | Check Python + TeX environments |
| `reproduce_computed_min.sh` | `reproduce.sh --comp min` | Run Phase A+B+C Python pipeline (~5 min) |
| `reproduce_computed.sh` | `reproduce.sh --comp full` | Run Phase A+B+C+D Python pipeline (~35 min) |
| `reproduce_documents.sh` | `reproduce.sh --docs` | Compile LaTeX documents |
| `reproduce_figures_from_results.sh` | internal | Sync figures |
| `check-system-deps.sh` | `reproduce.sh --envt` | Check system dependencies |

---

## Computational Reproduction (`--comp`)

The `--comp` option now runs the **Python notebook pipeline** in `Code/Python/`:

```bash
./reproduce.sh --comp min     # Phases A-C: calibration + Figs 1-3 (~5 min)
./reproduce.sh --comp full    # Phases A-D: all figures incl. 4-5 (~35 min)
```

Internally, these call:
- `reproduce/reproduce_computed_min.sh` → `Code/Python/run_all.sh --phase=ABC`
- `reproduce/reproduce_computed.sh`     → `Code/Python/run_all.sh --phase=all`

See `Code/Python/README.md` for:
- Python environment setup
- Kernel registration (`deferra2020-kz`)
- Per-notebook runtime estimates

---

## Document Compilation (`--docs`)

Builds `deFerra2020.pdf` from `deFerra2020.tex` using `latexmk`. Figures must
already exist in `Figures/` (generated by `--comp`).

```bash
./reproduce.sh --docs          # Compile main paper
./reproduce.sh --docs all      # Compile paper + all subfiles
```

---

## Environment (`--envt`)

Checks for:
- Python 3.12
- Required packages (`numpy`, `scipy`, `matplotlib`, `jupyter`)
- Jupyter kernel `deferra2020-kz`
- TeX Live / MiKTeX

---

## Logs

All runs create timestamped logs in `reproduce/logs/`.
Most recent log: `reproduce/logs/latest.log`

---

## Benchmarks

`reproduce/benchmarks/` contains timing data from past runs. See
`reproduce/benchmarks/README.md` for the benchmarking format.

Note: benchmark `.json` files may reference older environments; the
runtime estimates in `reproduce.sh --help` supersede them.
